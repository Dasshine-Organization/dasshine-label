# Dasshine Label 前端界面说明

## 设计概览

Dasshine Label 前端采用**深色科技感主题**，以蓝紫色渐变为主色调，体现专业、高效、智能的产品定位。

### 设计特色

- **品牌标识**：Logo 区域清晰展示 "Dasshine Label" 字样
- **深色主题**：保护视力，适合长时间标注工作
- **科技感**：发光边框、渐变效果、网格背景
- **交互友好**：悬停效果、动画过渡、即时反馈

---

## 页面结构

### 1. 登录页 (`/login`)

- 深色背景 + 网格纹理
- 居中 Logo + 品牌展示
- 渐变边框卡片
- 输入框悬停发光效果

### 2. 工作台 (`/`)

- 欢迎区域与统计卡片
- **业务入口**：按类别进入 `/projects?category=…`（真实项目，不跳演示 task）
- **演示入口**（仅开发或 `VITE_ENABLE_DEMO_ENTRIES=true`）：硬编码样例任务

### 3. 项目管理 (`/projects` · 可选 `?category=`)

- 项目卡片列表 + 类别 / 状态筛选
- URL `?category=nlp` 等与筛选标签同步
- 点击真实项目 → `/projects/:projectId/tasks`

### 4. 任务列表 (`/tasks` · 可选 `?category=`)

- 状态筛选（待领取/进行中/审核中/已完成）
- 可按项目类别收窄（如语料任务）

### 5. 标注工作区

| 路径 | 说明 |
|------|------|
| `/annotate-image/:taskId` | 2D 图像 |
| `/annotate-3d/:taskId` | 3D 点云 |
| `/annotate-embodied/:taskId` | 具身 |
| `/annotate-text/:taskId` | 语料 |
| `/annotate-audio/:taskId` | 语音 |
| `/annotate-video/:taskId` | 视频 |
| `/annotate-multimodal/:taskId` | 多模态 |
| `/annotate/:taskId` | 兼容跳转 |

**布局（以 2D 为例）：**
```
┌─────────────────────────────────────────────────────┐
│ 顶部工具栏 (返回 | 项目名称 | 进度 | 计时 | 提交)      │
├──────────────────────────┬──────────────────────────┤
│                          │                          │
│    画布 / 媒体区          │    标签与属性区           │
│                          │                          │
└──────────────────────────┴──────────────────────────┘
```

**典型交互：**
1. 从项目任务列表进入对应工作台
2. 完成标注并保存草稿 / 提交
3. 返回类别项目列表或任务列表继续

## 技术栈

- **框架**: React 18 + TypeScript
- **构建**: Vite 5
- **样式**: Tailwind CSS 3
- **UI库**: Ant Design 5（定制深色主题）
- **图标**: Lucide React
- **状态**: React Query + Zustand
